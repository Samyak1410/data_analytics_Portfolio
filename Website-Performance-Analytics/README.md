#  Website Performance Analytics Dashboard

##  Project Overview
This project analyzes website performance data to track user engagement, traffic trends, conversions, and device behavior. The dashboard helps stakeholders understand website effectiveness and identify opportunities to improve user experience and business outcomes.

##  Business Objective
The goal of this dashboard is to answer key questions such as:

- How much traffic is the website generating?
- Which channels drive the most visitors?
- What are the conversion rates?
- Which devices are most commonly used?
- How do user engagement metrics vary over time?
- Which pages have the highest bounce rates?

## Dashboard Features

### Executive Summary
- Total Sessions
- Total Users
- Conversion Rate
- Bounce Rate
- Average Session Duration

### Traffic Analysis
- Sessions by Source/Medium
- Traffic Trend Over Time
- Top Acquisition Channels

### User Behavior Analysis
- Page Views by Page
- Bounce Rate Analysis
- Session Duration Analysis

### Device Performance
- Desktop vs Mobile vs Tablet Traffic
- Conversion Rate by Device Type

### Geographic Analysis
- Website Traffic by Country/Region
- Conversions by Location

- Revenue per User

##  Insights Generated

Some business insights that can be derived:

- Mobile users generate the highest website traffic.
- Organic Search is the largest acquisition channel.
- Certain landing pages have significantly higher bounce rates.
- Traffic peaks during specific days and campaigns.
- Conversion rates vary across traffic sources.
